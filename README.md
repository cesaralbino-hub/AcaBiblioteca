# 📚 AcaBiblioteca
### Sistema de Gestión de Biblioteca

**Proyecto académico – Programación Avanzada | CUN 2026**

AcaBiblioteca es una aplicación de escritorio desarrollada en **C# y Windows Forms**, con una base de datos **SQL Server LocalDB**, que permite administrar información bibliográfica y gestionar préstamos y devoluciones de libros.

El proyecto fue desarrollado como parte de la Actividad de Construcción Aplicada (ACA) de la asignatura Programación Avanzada.

## 🎯 Objetivo

Desarrollar una aplicación funcional que integre programación orientada a objetos, interfaces gráficas, operaciones CRUD y persistencia de datos mediante una base de datos relacional.

## ⚙️ Funcionalidades principales

- Gestión de libros, autores, editoriales y usuarios.
- Registro, consulta, actualización y eliminación de información.
- Búsqueda de libros por código ISBN.
- Registro de préstamos y devoluciones.
- Actualización de existencias de libros.
- Reportes de préstamos activos, préstamos devueltos e inventario.
- Validación de datos y mensajes de confirmación.
